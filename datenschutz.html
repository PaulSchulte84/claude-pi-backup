für die private Anwendung claude-pi-backup

Was die Anwendung tut

claude-pi-backup sichert mit dem Programm rclone verschlüsselte Backups meines eigenen Raspberry Pi in mein eigenes Google Drive. Die Anwendung hat genau einen Nutzer, den Inhaber dieser Seite. Andere Personen können sie nicht nutzen.

Welche Google-Daten verwendet werden

  • Die Anwendung fordert nur den Bereich https://www.googleapis.com/auth/drive.file an. Sie sieht und bearbeitet damit nur die Dateien, die sie selbst in Google Drive angelegt hat.
  • Sie liest keine anderen Dateien in Google Drive und keine anderen Google-Daten wie Mails, Kontakte oder Kalender.
  • Die gespeicherten Dateien sind verschlüsselte Backups. Den Schlüssel hat nur der Inhaber.

Weitergabe und Speicherung

Daten werden an niemanden weitergegeben, nicht verkauft und nicht ausgewertet. Die Backups liegen nur im Google Drive des Inhabers. Die Zugangsdaten für Google liegen verschlüsselt auf dem Raspberry Pi des Inhabers.

Die Nutzung von Informationen, die über Google-APIs empfangen werden, entspricht der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use).

Privacy policy (English summary)

claude-pi-backup is a private, single-user application that uses rclone to store encrypted backups of my own Raspberry Pi in my own Google Drive. It requests only the scope drive.file and therefore accesses only files it created itself. It does not access any other Google user data, and no data is shared, sold or analysed. The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

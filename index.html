claude-pi-backup

Private Anwendung, kein öffentliches Angebot

claude-pi-backup ist eine private Anwendung. Mit dem Open-Source-Programm rclone sichert sie verschlüsselte Backups meines eigenen Raspberry Pi in mein eigenes Google Drive.

  • Es gibt genau einen Nutzer: mich als Inhaber dieser Seite.
  • Die Anwendung sieht in Google Drive nur die Dateien, die sie selbst angelegt hat (Bereich drive.file).
  • Die Backups werden vor dem Hochladen verschlüsselt. Den Schlüssel hat nur der Inhaber.
  • Es gibt keine Registrierung, keine weiteren Nutzer und keine Weitergabe von Daten.

Datenschutzerklärung

In English

claude-pi-backup is a private, single-user application. It uses rclone to store encrypted backups of my own Raspberry Pi in my own Google Drive. It only accesses files it created itself (scope drive.file) and shares no data with anyone. Privacy policy
